# ميقات الشام

تطبيق أندرويد لمواقيت الصلاة حسب موقعك، بتصميم مستوحى من سماء الشام وشعار جامع الصحابي أنيس الأنصاري.

- مواقيت الصلاة بطريقة رابطة العالم الإسلامي، مع اختيار مذهب العصر ومعايرة الأوقات
- تحديد الموقع تلقائياً أو اختيار المدينة
- تنبيه عند الأذان وتذكير قبله، بنغمات مختارة
- بوصلة القبلة، ورزنامة هجرية، وويدجت للشاشة الرئيسية

## التحميل

حمّل أحدث نسخة من صفحة [الإصدارات](../../releases/latest)، ثم افتح ملف APK على جوالك.
عند أول تثبيت سيطلب الجوال السماح بتثبيت تطبيقات من خارج المتجر.
